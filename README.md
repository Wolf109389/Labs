"haystack" (довільний текст) та "needle" (шукана стрічка). Програма повинна
знайти індекси всіх входжень стрічки "needle" в стрічці "haystack" та повернути
цей індекс, використовуючи метод скінченних автоматів для пошуку підстрічки у
стрічці
